Paste deliverables

One deliverable per line, with these columns separated by | and all of them required:
Title | Assignee name | Assignee email | Due date (YYYY-MM-DD) | Tower | Estimated hours | Ticket # (or N/A)
You can add a last column for Priority (High, Medium or Low); it is Medium if left out. The assignee's name and email must both match the same team member in this portfolio, and the due date must be after today. The start date is set to today.

Add from the address book

Import the Microsoft 365 address book

Every person is matched by email address. Use any one of these:
1. Outlook: open the distribution list or Microsoft 365 group, select the members, copy them and paste here (the "Name <email>; Name <email>" format works).
2. Outlook contacts export (CSV), or Microsoft 365 admin center > Users > Export users (CSV).
3. A plain list of email addresses.

Import deliverables from Microsoft Planner

In Planner, open the plan, choose the ... menu and select Export plan to Excel. Then choose that file here (.xlsx, or a .csv saved from it). Nothing is changed in Planner.
